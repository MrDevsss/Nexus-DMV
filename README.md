# DMV Driving School V2

A comprehensive driver licensing system for FiveM ESX servers.

## Overview

DMV Driving School V2 provides a complete testing and licensing workflow including written theory examinations, practical driving assessments, and automated documentation through an integrated receipt system.

## Core Features

**Theory Examination**
- Randomized question pool
- Configurable passing threshold (default: 70%)
- Instant scoring and feedback

**Practical Assessment**
- Multi-category vehicle support
- Checkpoint navigation system
- Speed compliance monitoring
- Vehicle condition tracking

**License Management**
- ESX license integration
- Automated receipt generation
- Test performance metrics
- Digital record keeping

**User Experience**
- QTarget interaction system
- Responsive NUI design
- Real-time progress indicators
- Mobile-optimized interface

## Technical Stack

- Framework: ESX
- UI: HTML5/CSS3/JavaScript
- Inventory: ox_inventory
- Targeting: qtarget
